## Definitions and units

| Symbol       | Formula                                     | Meaning                                          |
|:-------------|:--------------------------------------------|:-------------------------------------------------|
| T(p)         | t_init + t_mult_med + t_verify              | whole-program time for one run (s) at p threads  |
| t_mult_med   | median of r multiply repetitions            | parallel part only                               |
| S(p)         | T(1) / T(p)                                 | whole-program speedup                            |
| S_mult(p)    | t_mult(1) / t_mult(p)                       | speedup of the multiply phase only               |
| E(p)         | S(p) / p                                    | efficiency (1.0 = every core fully used)         |
| GFLOP/s      | 2n³ / t_mult_med / 10⁹                      | n³ multiply-adds = 2n³ floating-point operations |
| f_fit        | least squares fit of 1/S − 1/p = f(1 − 1/p) | Amdahl serial fraction, fitted to the data       |
| f_meas       | (t_init + t_verify) / T(1)                  | serial fraction measured from the phase times    |
| KF(p)        | (1/S − 1/p) / (1 − 1/p)                     | Karp–Flatt: estimated serial fraction at that p  |
| serial share | (t_init + t_verify) / T(p)                  | share of time spent in serial phases at that p   |
